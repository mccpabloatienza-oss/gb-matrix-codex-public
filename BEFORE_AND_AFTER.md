# Before and after

## Before this project

- The original Matriz GB was a working business tool developed with ChatGPT Plus from the author's domain knowledge.
- It belonged to a separate private repository and commercial context.
- It is not copied here and its Git history is not reused.

## After the Codex work in this repository

- A new independent repository structure exists for a safe public-demo candidate.
- A seeded generator creates a synthetic dataset from scratch.
- Generic indicator logic is isolated from presentation.
- Validation, tests, reproduction instructions and security gates are explicit.
- The browser demo explains the concept without exposing commercial data.

## Release state

- The independent repository was created with separate history, reviewed privately, merged into `main` and published after explicit authorization.
- GitHub Actions and local checks provide reproducible evidence; GitHub Pages serves the synthetic demo.
- The commercial repository remains private and is not part of this project.
